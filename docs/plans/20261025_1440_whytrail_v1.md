# whytrail v1: link plan files and code both ways, in time order, plus a backfill for old work
Worktree: /home/ukd/projects/whytrail-v1
Branch: feat/v1
Summary: A tool that links each plan to the code it changed and back, in time order, so we can always see why code exists.

## Goal
- Owner (2026-10-25 ~14:40): "every piece of code that we wrote is from plan file … the plan file could have a section that says these were the files edited … the code also can have a section which links it to the plan files associated with that code … in a time bound way … first we need to find which plan files belong to which code … this tool you can just map out the timeline of events with the plan files and the code itself … new restroom [neurastream] can be one of the consumers … should be in the same ecosystem". Main checked: no tool does this (git-ai and ORG-2 link lines to AI prompts/sessions; aiblame to agent names; none to plan files, none backfills). The name `planlink` is taken on npm; `whytrail` is free.
- Done = a Bun/TypeScript CLI `whytrail` (own repo, npm package `whytrail`) that (1) answers `whytrail why <file>[:<from>[-<to>]]` with every plan behind those lines, oldest first, each with date, title, first Goal line, current plan path and the commits; (2) answers `whytrail code <plan-id|path>` with the commits and files that plan changed, in time order; (3) stamps new commits with a `Plan: <plan-id>` trailer through git hooks and refuses commits without one; (4) backfills links for old commits into a committed `.whytrail/links.jsonl` with a source and a confidence for each link, and lists unsure ones for the owner to accept or reject.
