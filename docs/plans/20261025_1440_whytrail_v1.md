- [ ] P3b Lineage + story labels (INCIDENT I-20261025-168, INCIDENT I-20261025-169). (a) Link order, cheapest sure signal first: the P3 sources; then `cited-path` (the plan names a file the commit changes); only leftovers go to `semantic` = embedding similarity of plan text vs commit message + diff summary, inside a date window. The windows are measured, not guessed: from the high-confidence links, the 95th percentile of (code date − plan date) for plan-before-code and of (plan date − code date) for plan-after-code, written to `.whytrail/windows.json` and printed. (b) Cache by git blob hash: `.whytrail/cards.jsonl` holds one card per plan blob `{blob, plan, born, builds_on, files, outcome, confidence, source}`; a plan whose blob hash is unchanged is never re-read. Lineage queries read only cards, never plan bodies; in a lineage newer cards weigh more (weight = 0.5^(age_days/30)). (c) Story per plan: `Born from: bug|perf|feature|change|taste` (taste = the owner disliked a working thing) and `Builds on: <plan-id>[, …]`. Plans with those lines: read as-is (source `field`, confidence 1). Plans without them: Jev (TypeSafe AI API, key from env `TYPESAFE_API_KEY`) answers a Choice `born` over the plan's Goal section, and a Noul "B builds on A" for each candidate pair the lineage gives; confidence ≥ 0.8 → keep (source `jev`); below → GLM fallback writes the card (source `llm`); the `outcome` line of every card is written by the LLM (Jev does not generate text). No API key → those plans stay `unclassified`, never guessed. (d) `whytrail labels [--json]`: `bad (bug|perf|taste) by <later plan>: "<its first Goal line>"` when a later bug/perf/taste plan builds on it; `good` when ≥ 14 days old and no such plan builds on it; else `open`; a feature/change plan building on it changes nothing. (e) `whytrail review --sample 30` prints 30 random Jev cards for hand-checking; Main records agreement in Progress (target ≥ 90%). Fixture tests, written fail-before (each fails on the P3 code, passes after): unchanged blob → no re-read (classifier stub call count 0); B `Born from: bug` building on A → A bad with B's Goal line; B `Born from: feature` → A not bad; classifier stub confidence 0.6 → fallback path taken; no key → `unclassified`; windows computed from fixture links equal the hand-computed percentiles; A 13 days old → open, 14 → good. — difficulty: 4 — verify: `cd /home/ukd/projects/whytrail-v1 && bun test tests/labels.test.ts tests/lineage.test.ts`
